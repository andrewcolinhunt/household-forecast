# household-forecast

Compare how jobs, location, spending, and retirement dates affect household
finances. Calculate annual cash flow or project saved Plans through retirement
with [scenario forecasts](#run-forecast).

Open a saved SQLite database or start with an empty one, save your changes, then
download the updated database before leaving. Each browser session works on its
own copy. See [working with a database file](#database-files).

Start with the [example household](getting-started/index.md) or read about
[comparing decisions](#decision-planning).

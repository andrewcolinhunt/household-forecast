# Security

Report vulnerabilities privately to
[Andrew Hunt](mailto:andrewcolinhunt@gmail.com). If GitHub's **Report a
vulnerability** button is available on the Security tab, you can use that instead.

Include the affected version or commit, steps to reproduce the problem, and
its expected impact. Use fictional data. Do not post household databases,
account details, credentials, or unredacted screenshots in issues or pull
requests.

Security fixes target the current `main` branch. Older versions do not receive
separate security updates.
